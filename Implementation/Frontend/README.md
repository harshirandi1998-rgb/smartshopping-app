
# Frontend Development

## Purpose
The frontend provides the user interface of the SmartShopping application.

## Technologies
- HTML
- CSS
- JavaScript

## Main Features
- Customer Home Page
- Product Search
- Product Details
- Product Availability
- Current Prices
- Discounts and Offers
- Product Location
- Shopping List
- Customer Login
- Admin Dashboard

## Folder Structure
- public: Public files and images.
- src: Main frontend source code.
- components: Reusable UI components.
- pages: Application pages.
- styles: CSS files.
- scripts: JavaScript files.
- assets: Images and icons.
