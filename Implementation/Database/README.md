
# Database Management

## Purpose
This folder contains database structure, migrations and sample data for SmartShopping.

## Proposed Database
MySQL

## Main Database Entities
1. Customers
2. Administrators
3. Products
4. Categories
5. Stores
6. Inventory
7. Product Locations
8. Discounts
9. Shopping Lists
10. Shopping List Items

## Main Responsibilities
- Store product information.
- Manage product prices.
- Track product availability.
- Store discounts and offers.
- Manage supermarket information.
- Store customer shopping lists.
