
# API Documentation

## Purpose
This folder documents communication between the frontend and backend.

## Planned API Endpoints

### Products
- GET /api/products
- GET /api/products/:id
- GET /api/products/search

### Availability
- GET /api/products/:id/availability

### Discounts
- GET /api/offers

### Stores
- GET /api/stores

### Shopping Lists
- GET /api/shopping-lists
- POST /api/shopping-lists

### Authentication
- POST /api/auth/register
- POST /api/auth/login

## Development Status
API endpoints are planned and not implemented yet.
