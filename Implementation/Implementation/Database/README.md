
# Database Design and Management

## Purpose
The database stores and manages all information required by SmartShopping.

## Database Technology
MySQL (proposed)

## Main Database Entities

1. Customers
2. Administrators
3. Products
4. Categories
5. Stores
6. Inventory
7. Product Locations
8. Discounts
9. Shopping Lists
10. Shopping List Items

## Responsibilities

- Store product information.
- Manage product prices.
- Track product availability.
- Store discount information.
- Manage store locations.
- Maintain customer information.
- Store shopping lists.

## Folder Structure
- schema: Database structure and table definitions.
- migrations: Database changes.
- seed: Sample data for development.
