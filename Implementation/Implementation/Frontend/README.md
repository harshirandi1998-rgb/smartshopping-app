
# Frontend Development

## Purpose
The frontend provides the user interface of the SmartShopping application.

## Technologies
- HTML
- CSS
- JavaScript

## Main Features
1. Customer Home Page
2. Product Search
3. Product Details
4. Product Availability
5. Current Prices
6. Discounts and Offers
7. Product Location
8. Shopping List
9. Customer Login and Registration
10. Admin Dashboard

## Folder Structure
- public: Public files and images.
- src: Main frontend source code.
- components: Reusable UI components.
- pages: Application pages.
- styles: CSS files.
- scripts: JavaScript files.
- assets: Images, icons and other resources.
