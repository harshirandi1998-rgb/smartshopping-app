
# API Documentation

## Purpose
This folder contains documentation for APIs used by SmartShopping.

## Planned API Endpoints

### Product APIs
- GET /api/products
- GET /api/products/:id
- GET /api/products/search

### Availability APIs
- GET /api/products/:id/availability

### Discount APIs
- GET /api/offers

### Store APIs
- GET /api/stores

### Shopping List APIs
- GET /api/shopping-lists
- POST /api/shopping-lists

### Authentication APIs
- POST /api/auth/register
- POST /api/auth/login

## Development Status
Planned. APIs are not implemented yet.
